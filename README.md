# Ping-Pong-Ball-Launcher
Vex IQ Code for Ping Pong Ball Launcher Bot

## Project Overview
# This is my description for my ping pong ball launcher project: 
Hi this is the code for my ping pong ball launcher. I built it using VEX IQ blocks. It took me about 2 and a half weeks. I built the base and car first, then the loader and carriage. After that I built the aimer to aim up and down. Once I finished that, I started adding a few upgrades ( Hopper, Loader, Shroud, and weights to stop it from falling over ). The launcher loads itself with a ping pong ball, then you can either press the short range load or long range load. Then you shoot it and it reloads again. If it reloads 5 times, you need to refill it again. It is loaded by a rail and 2 gears with a motor to push the ball. I used two rubber bands to power the slingshot. For the loader, I used a part from sling in the vex app. There is a shroud to stop the ball from falling out of the carriage. when loading. The machine can also aim up and down. And, it can also move around like a car (Left, Right, Forward, Backward, Turn Left, and Turn Right).

My goal of this project was to be able to launch the ball short range and far range then reload the carriage with a ball on its own.

## Robot Components
The robot parts includes: 
- Base
- Aimer
- Loader
- Various Gears
- Hopper and Shroud
- Carriage
- Tracks
- Gears
- Grips
- Controller
- Brain/Hub

The Base is for moving around like left and right. The Aimer is meant to aim the ball up and down. The Hopper and Shroud are used for reloading the Carriage. The Controller is used to control the whole machine. The Brain is the one that runs all the code and stores it.

Some basic movements include: 
Joystick Forward = Move Bot Forward
Joystick Back = Move Bot Back
Joystick Left = Turn Bot Left
Joystick Right = Turn Bot Right
Aim up or down
Load short range or load far range
Shoot/Fire
Reload
